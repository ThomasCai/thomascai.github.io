# 📸 图片替换指南

## 需要替换的图片位置

所有图片都在 `exampleSite/static/images/` 目录下。

### 1️⃣ 个人头像和背景图
**位置：** `exampleSite/static/images/`

- **profile.jpg** - 你的个人头像照片（在"关于我"部分显示）
  - 建议尺寸：500x500 像素或更大的正方形
  - 格式：JPG 或 PNG
  
- **background.jpg** - 首页大背景图
  - 建议尺寸：1920x1080 像素或更大
  - 格式：JPG
  - 建议：选择专业、简洁的背景图
  
- **gus_small.jpg** - 移动端背景图（可选）
  - 建议尺寸：800x600 像素
  - 格式：JPG

### 2️⃣ Logo 图标
**位置：** `exampleSite/static/images/`

- **logo.svg** - 浅色主题 Logo（左上角）
- **logo-dark.svg** - 深色主题 Logo
- **favicon.png** - 浏览器标签页图标
  - 建议尺寸：32x32 或 64x64 像素

### 3️⃣ 项目展示图片
**位置：** `exampleSite/static/images/portfolio/` 或 `exampleSite/assets/images/portfolio/`

目前使用的占位图片：
- **hugo.png** - 用于 YOLOv8 和昇腾项目
- **hugothemes.png** - 用于 SAM 和运维系统
- **design.png** - 用于多模态问答和论文项目

**你需要添加的新图片：**
1. **yolo.png** - YOLOv8 项目截图/示意图
2. **sam.png** - SAM 标注系统界面截图
3. **multimodal.png** - 多模态问答系统截图
4. **huawei.png** - 华为昇腾相关图片
5. **ops.png** - 运维系统仪表盘截图
6. **paper.png** - 论文相关图片（可以是论文首页截图）

**建议尺寸：** 
- 宽度：780-1200 像素
- 高度：500-800 像素
- 格式：PNG 或 JPG
- 比例：大约 3:2 或 16:10

## 📝 如何替换图片

### 方法一：直接替换文件
1. 准备好你的图片（按照上面的命名和尺寸要求）
2. 将图片复制到对应目录：
   ```bash
   # 个人照片和背景
   cp your-profile.jpg exampleSite/static/images/profile.jpg
   cp your-background.jpg exampleSite/static/images/background.jpg
   
   # 项目图片
   cp your-yolo-image.png exampleSite/static/images/portfolio/yolo.png
   cp your-sam-image.png exampleSite/static/images/portfolio/sam.png
   # ... 以此类推
   ```

### 方法二：更新配置文件引用
如果你的图片名称不同，可以修改 `exampleSite/data/content.yml` 文件中的图片路径。

例如：
```yaml
portfolio:
  portfolio_list:
    - name: YOLOv8 小目标实例分割优化
      image: 'images/portfolio/你的图片名称.png'  # 修改这里
```

## ⚡ 图片优化建议

1. **压缩图片**：使用工具如 TinyPNG 压缩图片，减小文件大小
2. **统一格式**：项目截图建议使用 PNG（保持清晰度）
3. **背景图**：使用 JPG 格式（文件更小）
4. **响应式**：准备不同尺寸的图片以适配移动端

## ✅ 替换后的验证

替换图片后，Hugo 会自动检测变化并重新构建网站。在浏览器中查看：
- 刷新页面确认图片已更新
- 检查移动端显示效果
- 确保图片清晰且加载速度快
